# DR3FP Public Builds

DanceRail3FanmadePlayer (DR3FP) is a fanmade chart player for the mobile rhythm game DanceRail3. It is a clean rewrite which uses no code from other projects, except for gameplay (the 'game' scene).

## Usage
Windows & Android: Download from [GitHub releases](https://github.com/swordalt/DR3FP-Public/releases).<br>
iOS: Not available yet.
